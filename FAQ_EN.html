1General

What does the PS5 Dump & Image Converter do?

It converts backups of PS5 games between the common formats, unpacks them, packs them and checks them – through an interface with eight clearly separated tasks. On top of that come tools for working with a PS5 that is already jailbroken: finding the console, starting payloads, library, save data, AMPR EMU, BACKPORT and more.

The program is meant only for content you own and acquired legally.

Which formats does the program know?

FormatWhat it is
Dump folderA normal folder with the game's files (eboot.bin, sce_sys …).
.ffpfscCompact, compressed container – one single file.
.ffpfsLike .ffpfsc, but uncompressed: larger, but faster to build.
.exFATA real file system image in exFAT format.
.ffpkgContainer with a UFS2 file system; checked automatically after writing. Windows only.

The program can read packages (.pkg, .fpkg) and show them in the library; PS4 packages are converted with dedicated tools (see section 4).

Which target format should I choose?

For a USB drive and for passing a game on, .ffpfsc is usually the best choice – it is compressed. .ffpfs builds faster but is larger. You only need .exFAT and .ffpkg when another workflow expects exactly that format.

On a USB drive the console does not read a loose folder but a container that ShadowMount+ mounts. That is exactly why task 1 turns a dump folder into one single file.

Which systems does the program run on?

On Windows (ready-made EXE), Linux and macOS. On Linux and macOS two paths are missing that only work with Windows tools:

  • reading and creating .ffpkg – that is, task 4 and .ffpkg as target format (UFS2Tool and the Dokan driver exist only for Windows),
  • the fallback paths via OSFMount (these only kick in for unusual images anyway).

Everything else – dump folder, .ffpfsc, .ffpfs and .exFAT in every direction, batch conversion, AMPR EMU Manager and Validator – is fully available there.

2Installation and start

Why does Windows ask for administrator rights at startup?

The Windows version always requires administrator rights – among other things for the .ffpkg paths (UFS2) and for mounting with OSFMount. If you decline the prompt, the program does not start. On Linux and macOS it starts as a normal user.

My antivirus flags or removes the EXE. What can I do?

Programs built with PyInstaller are occasionally flagged by mistake. The program does not add any exceptions to your antivirus and does not install certificates. Only get the EXE from the project's own source; if the source is right, you can add the file as an exception in your antivirus yourself.

The Linux file does not start. Why?

  1. Make the file executable once (X.Y.Z stands for your version): 
    chmod +x PS5_Dump_Image_Converter_vX.Y.Z_linux_x86_64
  2. The ready-made Linux file needs a current system (system library glibc 2.42 or newer, for example Ubuntu 26.04). It does not start on older systems such as Ubuntu 24.04, Linux Mint 22 or Debian 13.
  3. In that case build the program on your own computer – in the project folder with ./Build_Linux.sh, without sudo. If Tcl/Tk is missing, the script names the matching install command.

On the Mac, “the developer cannot be verified” appears.

macOS marks everything that arrives via browser, mail or AirDrop. The install script (Install_macOS.sh or Erste Installation.command from the disk image) removes the mark itself. By hand it works like this:

xattr -dr com.apple.quarantine "/Applications/PS5 Dump & Image Converter.app"

Note: a Mac version only fits Macs of the same type – a version for Apple Silicon does not run on an Intel Mac and vice versa.

Do I need OSFMount, Dokan or other additional programs?

Normally not. The program reads .exFAT images with its built-in reader – without mounting, without administrator rights, on every system. OSFMount is only the fallback on Windows for unusually built images; the program then says so and can install OSFMount itself. FileZilla is optional and only needed for the FILEZILLA button.

3Converting and formats

How do I convert safely?

  1. Choose the matching task on the left.
  2. Choose the source with the button next to SOURCE.
  3. If shown, choose the TARGET FORMAT – and, if needed, compression and workers.
  4. Choose a separate TARGET FOLDER and a writable TEMP FOLDER.
  5. Check all paths and press START.
  6. Keep the program open until the log reports successful completion.

Rule of thumb: keep a copy → matching task → separate target folder → enough space → wait for the success message. Delete the originals only once the result is finished and, if needed, checked with task 8.

How much free space do I need?

The program calculates this before starting and tells you if it is not enough. As a guide, relative to the size of the source:

Target formatSpace needed, roughly
.ffpfsc0.75 times
.ffpfs, .exFAT1.1 times
.ffpkg1.3 times

If AMPR EMU or BACKPORT is ticked, a complete working copy of the game is also created in the work folder. If the work and target folders are on the same drive, the sum counts.

A run stopped with “The source folder was emptied during the build”. What happened?

The working copy in the temp folder lost its files during the build – not through the program. A common cause is Windows Storage Sense: when space runs low it deletes files in the Windows temp folder. Choose your own folder on a large drive under TEMP FOLDER below (e.g. D:\PS5-Temp) and repeat the run. The program warns at the start of a run when the temp folder is at risk; batch conversion removes working copies after each game. With Dump folder: create a working copy first the question before an integration is also skipped.

Which compression level is right?

1 is the fastest, 9 gives the smallest file; for a start, “6 – Balanced” is enough. Don't expect miracles: PS5 game data is largely compressed already. Measured on a 664 MB dump, levels 1 and 9 differed by only about 5 % in size – higher levels mainly cost time.

What do WORKERS and VERIFY mean?

WORKERS sets how many operations run at the same time. One processor core always stays free, and very large images are throttled further. You set it with the rotary knob – turn it with the mouse, use the mouse wheel or the arrow keys; a double-click resets it.

VERIFY decides whether the finished image is checked after packing: “Quick” checks the structure, “Full” also reads everything back and takes considerably longer.

Can I change a finished image afterwards?

Not directly – a finished image has no free space for additional files. There are two ways, though:

  • Build the same format again, with integration (tasks 2 to 6): the same file as source, the same format as target, tick what should go in (asset pack, PlayGo, BACKPORT) and start. The program unpacks, integrates and rebuilds; you need the game's size once as free space in the work folder.
  • Unpack into a dump folder, edit the folder yourself and pack it again.

What is “Dump folder (with integration)”?

If AMPR EMU, PlayGo or BACKPORT is ticked in task 1, this target format appears in addition. Then no image is created, but a dump folder with exactly these integrations. At the start the program asks where to integrate:

  • Into a backup (recommended) – the dump is copied into the target folder and only the copy is changed.
  • Into the original – directly in your folder. The files are no longer original afterwards; BACKPORT replaces eboot.bin and libraries without a backup. This cannot be undone.

Can the computer shut down on its own after a long conversion?

Yes – with the checkbox Shut down the computer after a successful run under TEMP FOLDER. Only after a successful run does a window appear that counts down 60 seconds (cancel with the button or ESC). Then images are unmounted, working files removed and the log saved, and the computer shuts down without further questions. After an error or a cancellation it stays on. Save your work in other programs beforehand.

Does it also work without the interface, from the command line?

Yes, every task also runs without a window – using the same workflow logic as the interface (X.Y.Z stands for your version):

PS5_Dump_Image_Converter_vX.Y.Z.exe --cli --task 1 --source "D:\Dumps\Game" --dest "D:\Output" --format ffpfsc --yes

--format knows folder, ffpfsc, ffpfs, exfat and ffpkg; --yes confirms prompts, --shutdown-on-success shuts down afterwards. On Windows, open the command prompt or PowerShell as administrator – otherwise the call stops with return code 3.

How do I convert several files or dump folders at once?

With task 5 – Batch conversion: click Choose sources and decide whether they are dump folders or image files (.ffpfsc, .exFAT or .ffpkg). For dump folders the Windows folder dialog opens: mark several folders with Ctrl or Shift, then click Select Folder. A folder that is not a dump itself (such as Game Dumps) stands for all the dumps and images inside it. Then set one common target format and start. Every source is processed and checked on its own; if one fails, the others still run to the end. Test a single source first and check that there is space for all results.

How do I check a backup without changing anything?

With task 8 – Validator. It reports missing required files, a damaged file system or wrong nesting. For .ffpfsc and .ffpfs it looks one level deeper without unpacking: nesting: fine is the result you want, wrongly nested means the file has to be created again.

Not checked is not a verdict: an .ffpkg can only be checked with administrator rights. Without them the result is NOT CHECKED – not “failed”. On the command line, task 8 then returns 4 (0 = fine, 1 = problems found).

A run was cancelled or failed. What now?

After CANCEL, wait for the confirmation in the log. Do not keep using an incomplete result – delete it and start again with checked paths. If a warning appears, read the full message and fix the stated cause first instead of changing several things at once. Keep the log and the source until the cause is clear.

4On the PS5

What has to be prepared on the console?

  • A PS5 that has already been prepared with a jailbreak method of its own – the program does not perform this step.
  • ShadowMount+, which mounts the images.
  • For transfers, an FTP payload: ftpsrv on port 2121. The program starts it on request via the ELF loader (port 9021).

Where does the image go on the USB drive?

Directly into the root of the drive – or into the folders homebrew or etaHEN/games on it. ShadowMount+ only searches fixed places (USB drives usb0 to usb7, plus /data/homebrew, /data/etaHEN/games and the M.2 expansion). An image in a subfolder of your own is not found.

An entry in ShadowMount+'s manual.lst does make a folder of your own reachable, but it does not reliably survive a restart: with several USB devices attached, the drive number can change.

Which FTP payload should I use?

Bundled and preset is ftpsrv-ps5 on port 2121; the program has been tested with it. After every upload the program checks whether the files are executable and warns in the log otherwise.

The game does not start. What do the error codes mean?

CodeCause and remedy
CE-108255-1An incomplete .ffpkg – or starting from internal storage instead of the USB stick. Try the backup from the stick.
CE-107891-6An update package does not match the installed base package (even a rebuild of the same game counts as a different package). Install the matching base package or rebuild both together. Which updates exist for a game is shown by PS4 PKG Dump & Image Converter in the Parts column.
CE-100096-6The console rejects a self-built package. For game backups the way via image and ShadowMount+ is the right one; for your own homebrew use Install app directly.

What is AMPR EMU, and when do I need it?

When a game starts, the PS5 asks its APR file resolver where the game files are. If the game runs from a mounted image, the resolver gets no usable answer – and the game does not start. AMPR EMU is a replacement library that answers this question on its behalf. You need it for games that are meant to run from an image.

You can integrate it while creating (checkbox AMPR EMU in tasks 1 to 6) or via button 7: it opens a selection with the new method (ShadowMount+ from 1.7 alpha8), the old method (up to alpha6) and Build AMPR EMU into the backup. The program checks itself which ShadowMount+ version runs on the console and, if necessary, advises you to use the other button.

If AMPR EMU has no effect, check the ShadowMount+ config.ini: if the game's title ID is listed under fakelib_exclude, ShadowMount+ from version 1.7beta4 on mounts no fakelib at all for this title. Button 7 and the AMPR trace assistant ask in this case before placing anything; you remove the entry under MORE TOOLS → SHADOWMOUNT+.

What are asset packs?

With the method Asset pack, the game files are additionally put into packed bands (ampr_assets-*.pak) that AMPR EMU reads block by block from version 0.4.2.1 on. This saves space and file descriptors on the console. For this, both drop-down lists must be right: AMPR version test-pack (or test-debug-pack for troubleshooting) and method Asset pack – the version test-nopack that is preselected at the top cannot do it.

Every packed block is checked byte by byte against the original file. Your original files stay in place unless you choose otherwise; only leave them out after a successful test on the console. The detailed guide opens with the Asset Packs Guide button.

What does the “PlayGo” checkbox do?

It places a replacement for libScePlayGo.sprx in the game that reports all language and scenario packages as installed. Most games do not need this, so it is off by default. If a title declares PlayGo content and the checkbox is not set, the program asks at the beginning of the run – before anything is copied, unpacked or packed.

What does BACKPORT do?

A PS5 game records which development kit (SDK) it was built with; the console starts nothing that is newer than its firmware. BACKPORT (under MORE TOOLS) lowers this value to a target firmware – 4.00, 5.00, 6.00 or 7.00 – and places matching replacement libraries in a fakelib folder. Beforehand the list shows every file and what would happen to it; a backup of the folder is preset.

The result only runs on a jailbroken console. Whether a game starts after the backport cannot be told in advance – keep the backup until it runs on the console. The Check coverage option shows whether functions the game requires are missing from the replacement libraries.

How do I turn an ELF into an eboot.bin?

ELF → EBOOT.BIN (under MORE TOOLS) wraps an .elf – for example a homebrew you built yourself – as eboot.bin: a SELF wrapper with the ELF inside. Afterwards the program reads the file back as a check. A file that is already a SELF, a stripped ELF and anything that is not an ELF are refused with a note.

The eboot.bin is a fake SELF without a real signature and only starts on a jailbroken console.

Does a tile I create appear under Games or under Media?

That is not decided by the eboot.bin but by sce_sys/param.json: its field applicationCategoryType puts the tile under Games with 0 and under Media with 65536. The console reads it when the app is installed or registered; afterwards it can only be changed by installing again. In Install app directly (MORE TOOLS) you choose it under Tile under; Media is preset.

Can I use PS4 games too?

Yes. PS4 PKG Dump & Image Converter (MORE TOOLS) reads your PS4 packages and turns base, update and optionally DLC into a normal game folder (format Dump folder), an image for ShadowMount+ (ffpfsc or exFAT) or a merged package. ONLINE UPDATES downloads missing updates for PS4 games from Sony. PS5 packages cannot be unpacked; More → Read package header shows their structure.

Trophies: a PS4 game that starts from an image does not register its trophies (Trophy registration failed, 0x80551618). This is by design and not caused by the image. If you need the trophies, install the game with the Package Installer. PS5 titles are not affected.

Can I send a package to the console over the network?

Yes, with PS4 PKG Dump & Image Converter (MORE TOOLS): read in the packages, choose a game, press SEND TO CONSOLE and enter the console's address. There are two ways: on a PS5 the OnionHEN package manager (called DPI v2 in Console & payloads) receives the package and installs it; a PS4 fetches it from the PC through the Remote Package Installer. Detect asks which service answers at the address.

Untested: sending has not yet been tried on a console – both ways are tested against stand-ins for the services. Whether a particular package starts afterwards can only be told by trying.

A game hangs on the loading screen.

Some titles stay at a “Please wait” when started from the image, while the same package runs when installed with the Package Installer. Ruled out so far: the storage location, missing PlayGo content, an online check and an incomplete image – the cause is still open. By no means every title is affected.

5Console, library and payloads

What does the CONSOLE view show?

Below the logo, CONSOLE › switches to a second view with eight tools: Console & payloads, WebKit Autoloader, Library, Prospero Manager, CoolSysCent-Pro, ShadowMount+, SMPlusGui and BFpilot. ‹ CONVERT leads back; the source, settings and a running job are kept.

Console & payloads already finds the PS5 by itself when the program starts – you do not have to enter an address. The page queries all known ports, shows state, version and purpose for every service, starts missing services from the bundled helloworld folder and opens web interfaces. On Windows these appear directly in the program, otherwise in the browser.

Prospero Manager, CoolSysCent-Pro (the PS5 Cooling & System Center, port 8086), ShadowMount+, SMPlusGui and BFpilot (a second file manager, port 5905) have no page of their own: one press checks whether the payload is already running on the console, sends it by itself if needed – together with the ELF loader if port 9021 is still closed – and then opens its web interface.

The FTP server is shown as “hangs”. What does that mean?

An aborted download can put ftpsrv into a state in which it keeps accepting connections and then stays silent. A freshly loaded payload does not help then – only a restart of the console. That is why the program checks not only the port but also whether the service answers.

Why does “Cancel” stop a download from the PS5 only after the current file?

On purpose: a download aborted in the middle of a transfer cripples ftpsrv (see above). The program remembers your request and ends the transfer as soon as the current file has arrived completely.

What can the library do?

  • This PC: searches your scan folders for dump folders, images and packages and shows them as cards or a list – with cover image, platform, format and integrations.
  • PS5: shows the backups at the usual storage locations and the installed PS5 and PS4 games.
  • Info & metadata names version, SDK and required firmware – and “BACKPORT required” when the game needs more than your PS5 has.
  • Start starts a title on the console via websrv (port 8080); if a game is running there, it is closed – the program asks first.
  • Copy sends to the PS5 or downloads from it, Convert takes an entry over as the source.

A longer search shows a window with a progress bar and percentage and can be cancelled.

How do I back up save data?

Backing up, decrypting and transferring between users is done by the Garlic Save Manager with its own interface (port 8082). There is no page of its own for it: on Console & payloads you select it in the table, start it with Start selected and open its interface with Open web interface. Make a backup before every write-back. A newly created console user finds its save data empty – the old saves stay with the original user.

What does the WebKit Autoloader do, and which version should I use?

It creates the tile WebKit Autoload on the console (home screen, under Media) so that the entry can be repeated with one press. It consists of a host on your computer – as a Windows program or as a Python script – and an installer that runs once on the console. Both are under CONSOLE › WebKit Autoloader.

  • Version: Several are bundled, from v0.4.0 to v0.6.0. The latest is preselected; the program remembers your choice, and it applies to all three paths (host as Windows program, host as Python script, send installer). If the latest does not work for you, try an older one.
  • Host: It occupies DNS (UDP 53) and HTTPS (TCP 443) and therefore needs administrator rights.
  • Installer: It goes to the console via port 9021. If the port is closed, it goes via FTP to the root of a USB drive; you pick it up there with the Payload Manager.

If a new version appears, put its three files into the folder PS5 WebKit Autoloader in addition; the older ones stay selectable.

The ShadowMount+ button does not open a web interface. Why?

By default ShadowMount+ listens only on the PS5 itself (api_bind_address=127.0.0.1). From your PC, port 10101 is then closed even though ShadowMount+ is running – and the button still sends the payload once more. If the port does not answer afterwards, the log states the reason. So set the key api_bind_address in the ShadowMount+ editor (MORE TOOLS) to the PS5 address or 0.0.0.0. The interface has no login – do not use this on a network you do not control.

How do I use other controllers on the PS5 (AnyPad PS5)?

Since v1.9.60 the payload AnyPad PS5 is bundled (now version 0.6.0-beta). It makes Bluetooth controllers usable on the PS5; games see them as a DualSense. According to its author, the DualShock 4 v2, 8BitDo SF30 Pro (Switch mode) and GameSir G7 SE are verified; Xbox and Switch Pro controllers among others are supported but not yet verified. On Console & payloads you start it with Start selected and open its pairing page (port 8095) with Open web interface.

  • When the console asks who uses the controller, the author advises choosing Quick play / Guest (a temporary user).
  • A DualShock 4 has to be paired again each time you switch it on; other controllers reconnect by themselves.
  • Always stop AnyPad with the button on its web interface, also before starting it again.
  • The page asks for no PIN: anyone on the same network can use it.

Since October 2026 the project lives on Codeberg; port, page and usage notes come from the author's information.

Does the program change anything on my console?

Only what you trigger: it sends payloads (they run until the console's next restart) and transfers files via FTP to the places you choose. In the library it renames nothing on the PS5, it only reads the list of installed games, and it writes nothing into the console's system databases.

6Problems and help

START stays greyed out.

Check whether source, target folder and temp folder are all chosen. Task 8 needs no target folder. If the source is rejected, the chosen task does not fit the file type – then use task 6 or check the source with task 8.

Message “sce_sys/param.json missing” or “param.json has no Content ID”.

param.json missing: the game is incomplete. With Yes the program creates a valid param.json and carries on building; with No it stops – in that case it is better to create a new backup from the original.

Content ID missing: title and content ID are not in any file of a backup, only the title ID. With Look up missing metadata online (settings) the program fetches both. Otherwise it enters a placeholder (UP0000-<Title-ID>_00-…); the old file is kept as param.json.alt. For updates and DLC the real content ID has to be entered.

Message “eboot.bin not found in the source folder”.

An image has to carry the game directly in its root: eboot.bin and sce_sys/param.json sit in the folder itself, not in a subfolder – that is what ShadowMount+ requires. The program checks this before building (for .ffpfsc, .ffpfs, .exFAT and .ffpkg) and stops otherwise, instead of the problem only showing up on the console. Usually the chosen folder is one level too high – pick the folder in which eboot.bin sits directly.

How do I get help with an error quickly?

Press DIAGNOSTICS. The report contains version, system, the last log lines and an assessment of the display; credentials are blacked out automatically. It is saved as Diagnosebericht_<date>.txt in the settings folder. Also mention the chosen task, the source type and the last visible message – private paths or personal data only if they are needed for troubleshooting.

What is the “doctor”?

The environment check answers the most common causes within seconds: long paths in Windows, the file system of the folders (FAT32 ends at 4 GB per file), free space and write permission, whether the bundled programs start, whether the settings file is intact. Run it in the program folder – on Windows in a command prompt opened as administrator (X.Y.Z stands for your version):

PS5_Dump_Image_Converter_vX.Y.Z.exe --doktor "E:\PS5_Temp" "E:\Target"

Both folder arguments are optional. [ ok ] means fine, [ !! ] a note, [FEHL] a real error, [ -- ] not needed. The check makes no connection to the internet; the same information appears in the DIAGNOSTICS window.

The interface is too small or too large.

Under SETTINGS → Display: scaling and resolution you set the scaling (slider, 100 to at most 300 %, limited by the screen width) and the screen resolution by hand. Apply with Apply and restart; Reset to automatic restores the default.

How do I change theme, background image and language?

  • THEME: four color schemes (Futuristic, Dark, Light, Metallic); after APPLY the program restarts.
  • SETTINGS: 20 bundled images each for the main area and the sidebar, or an image of your own, plus sliders for see-through, brightness and contrast. Light images are meant for the Light theme.
  • EN / DE: switches the whole interface including the log between English and German – this FAQ then also opens in German.

Does the program send data to the internet?

On its own only a lookup of missing metadata: if title, publisher or category are missing, the game's title ID goes to store.playstation.com as well as prosperopatches.com (PS5) or orbispatches.com (PS4). Fetched details are kept for 30 days. By default this is on under Windows and Linux and off on the Mac; you can change it in the settings under Metadata from the internet. At startup the program also searches for the PS5 in your own network – that does not leave your home network. Downloads and updates only run when you press the button.
