# PS5 Dump & Image Converter v1.9.46

- **Neu:** Weboberflächen der Konsole (Payload-Manager, Garlic, Web-Dateimanager …) öffnen unter Windows im Programm und füllen dort die ganze Fläche; unter Linux und macOS weiter im Browser.
- **Neu:** Die Dienstetabelle zeigt die Version jedes Payloads, und die Firmware steht wie auf der Konsole, etwa „12.00“.
- **Geändert:** Das Programm startet immer in der Ansicht UMWANDELN.

## Downloads

- **Windows:** `PS5_Dump_Image_Converter_v1.9.46.exe` (benötigt Administratorrechte beim Start).
- **Linux (x86-64):** `PS5_Dump_Image_Converter_v1.9.46_linux_x86_64` – nach dem Download ausführbar machen:

  ```
  chmod +x PS5_Dump_Image_Converter_v1.9.46_linux_x86_64
  ```

- **macOS:** `PS5_Dump_Image_Converter_v1.9.46_macos_arm64.dmg` (Apple Silicon) und `PS5_Dump_Image_Converter_v1.9.46_macos_x86_64.dmg` (Intel). Meldet macOS beim ersten Start „Der Entwickler kann nicht überprüft werden“, hilft Abschnitt 19.3 im Benutzerhandbuch.
- **Prüfsummen:** `SOURCE_FILE_MANIFEST_v1.9.46.sha256` listet die SHA-256 aller Quelldateien dieser Fassung.
